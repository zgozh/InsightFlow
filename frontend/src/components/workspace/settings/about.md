# About InsightFlow

InsightFlow is an individually maintained business analytics workbench for governed data access and reviewable results.

The product brings together registered data sources and metrics, authorized queries, audit history, analysis traces, and report publishing. Ordinary chat tools and operator-configured integrations have separate boundaries from Analytics query governance.
